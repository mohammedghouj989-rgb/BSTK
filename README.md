# BSTK - Byte Security Toolkit

Welcome to **BSTK**! A lightweight, custom-built security toolkit developed entirely on a mobile device. 

## About The Project
This project is a collection of custom tools written in Python, designed to be lightweight and efficient for basic network reconnaissance and security testing. 

## Current Tools
- **Port Scanner:** A custom Python script to scan for open ports on a specific IP address.
- **Launcher:** A simple command-line menu to manage the tools.

## How to Use
1. Clone the repository:
   `git clone https://github.com/mohammedghouj989-rgb/BSTK.git`
2. Navigate to the folder:
   `cd BSTK`
3. Run the launcher:
   `python3 byte_tools.py`
